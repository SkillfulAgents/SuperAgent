# Slussen

Slussen Regular and Medium by [Blaze Type](https://blazetype.eu), licensed to
Datawizz Inc. for use in Gamut. These files are **not** covered by this
repository's MIT license and may not be reused, modified, or redistributed
outside this app.

The bundled WOFF2 files are compressed from the Version 2.000 Regular and
Medium TTFs supplied by Blaze Type. They retain the original outlines,
hinting, spacing, and layout tables without subsetting. Conversion uses
fontTools 4.67.0's WOFF2 compressor with `transform_tables=set()`.

Loaded by the `@font-face` rules in `src/renderer/globals.css`.
